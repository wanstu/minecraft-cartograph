DESIGN BASELINE / 2026.11

Cartograph · 最终交互规范

这是 Minecraft 地图册模组的原生开发依据，不是游戏运行时界面。大地图用于交互与管理，小地图用于常驻 HUD 展示。两者共用真实已生成地表数据、图层、地图风格、标点和命名区域。HTML 地形用于设计评审，正式模组必须读取真实世界数据。

打开大地图高保真打开小地图 HUD

设计哲学

  • 原生 Minecraft：采用 Minecraft 原生屏幕与 HUD，不引入 WebGUI/Chromium。
  • 数据与显示分离：同一份真实世界快照驱动像素、写实、手绘三种画风。
  • 一次投入，多次更新：沿用地图册的耗材机制；已付款绘制区块更新不重复扣费。
  • 只绘真实已生成地形：不靠 Seed 推测未生成区块，不画地下地形和未知结构。
  • 单一设置入口：风格和小地图 HUD 配置统一从大地图“设置”进入。
  • 轻量级小地图：不做交互按钮，不需要游戏中移出鼠标准星操作。

三个地图风格

像素

Minecraft 地表方块色、硬边像素、VoxelMap 风格，视觉以 MC 世界为准。

写实

现代地形地图：自然色彩、地形阴影、水系与道路，偏信息表达。

手绘

羊皮纸、墨线、山脉森林符号与地名，偏古式地图表现。

风格切换只重绘已有地图缓存，不应该触发世界扫描或扣除墨水。

大地图顶部菜单顺序

位置入口交互与去重原则
1图层最高频。道路 / 铁路 / 结构 / 标点 / 区域名称及边界 / 等高线。
2标点列表、定位、新建（地图点击选点或手动输入 X / Z）。
3区域列表、圈选多边形、改名、改边界、定位与删除。
4地图册资源和扩页说明；不重复放置设置入口。
5设置大地图风格和小地图 HUD 的唯一主设置入口。
6信息地图/维度/标点与区域统计，不放多余操作。
7返回返回游戏。居中按钮独立放在右下角，不占顶部菜单。

地图左键 / 右键行为

  • 左键选点：地图位置出现清晰选中点；详情浮窗显示坐标、所属区域、地形/地物信息和可用操作。拖动画布不应误触发选点。
  • 标点详情：定位、编辑、删除；不存在“在详情里添加另一个标点”。
  • 区域详情：定位、编辑名称和备注、调整已有边界、删除；不重复提供新增区域入口。
  • 右键菜单：在此添加标点、在此开始圈选区域、查看位置详情、以该处居中。
  • 区域圈选：逐点布置至少三个顶点；切换到调整模式后可拖动顶点、双击边线插入顶点、右键顶点删除；已有区域直接加载旧边界编辑。

左下角状态浮窗

  • 默认：当前世界/维度、地图选中坐标、缩放倍数。
  • 操作提示：左键查看详情、右键操作、拖拽平移、滚轮缩放。
  • 发生交互：显示最近成功操作，不放多余的示例统计或无用 UI 标识。
  • 固定在左下角，占用较小面积，不阻挡地图右侧控制面板。

地图册资源的准确用语

字段说明
扩展地图页每增加一张原版空地图可在工作台增加一页 128×128 方块覆盖范围。不是货币兑换；可见范围由地图册容量和真实测绘状态决定。
普通墨水用于首次测绘，重复更新同一已缴费区块免费。显示余额与容量。
彩色染料红色 / 黄色 / 蓝色三种独立染料槽，集齐后解锁彩色绘制。风格不额外消费墨水。
发光墨水控制发光标点，与地表颜色渲染分离。
指南针装入后显示玩家位置；允许取出，不等于 HUD 配置。
地图册资源应使用真实物品槽：墨囊与发光墨囊作为消耗品，红色、黄色、蓝色染料分别占三个槽，全部装入后启用彩色绘制；指南针可以装入和取出。游戏内所有材料变更应由服务端验证并确认。

小地图的最终定位与设置

独立小地图 HTML 是纯 HUD 视觉，不存在可点击按钮。实际游戏中玩家无法直接对小地图点按；所有设置都在大地图 → 设置 → 小地图设置进行。

设置表现与验收
锁定方向 / 不锁定方向锁定时始终北向上；关闭时地图随视角旋转，玩家箭头保持直观。
显示东西南北在地图外圈叠加 N / E / S / W，允许隐藏。
方形 / 圆形切换 HUD 的剪裁形状，不改变地理信息或扫描。
拖动设置位置从大地图设置进入完整游戏画面调整模式。除小地图外游戏画面不接收操作；拖住小地图改变 HUD 位置，按屏幕比例保存。
游戏画面调整大小在完整游戏画面里拖动小地图右下角手柄，实时改变 HUD 尺寸；完成后返回大地图设置。
显示坐标 / 区域地名 / 地图图标各自独立开关，不阻挡主要游戏画面。

验收路径与开发限制

  • 在大地图设置依次选择像素、写实、手绘，确认世界地图底图发生明显且真实的视觉变化；切换过程中地图不重新扫描。
  • 打开地图册 → 材料槽 → 投入墨囊/发光墨囊、分别装取红黄蓝染料、装取指南针 → 资源状态实时更新。
  • 地图左键选点 → 选中点与详情浮窗出现；当详情已打开时，点击弹窗外其他位置只关闭旧浮窗，不立即打开第二个浮窗；拖动或缩放地图时自动关闭。
  • 右键添加标点 → 可输入负数/正数 X、Z 坐标，选择 16 种图标 → 保存后能查看、编辑、删除。
  • 选择区域 → 逐点圈选 → 切换到调整顶点 → 拖动顶点 / 双击边线加点 / 右键删除顶点 → 保存名称、类型、注释；已有区域直接编辑原顶点。
  • 设置 → 小地图设置 → 方/圆、方向锁定、方位字母、坐标、区域名称、图标、缩放级别 → 进入游戏画面拖动 HUD 与右下角尺寸手柄 → 完成返回大地图设置。正常游戏中的小地图不出现操作按钮。
  • 原生模组的真正性能、区块真实内容和资源一致性仍需另外做游戏客户端验收，HTML 不代表 JAR 已实现。
