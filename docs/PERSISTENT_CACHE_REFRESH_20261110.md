# Cartograph 持久化地图缓存与并行刷新（2026-11-10）

## 实现

- 地表源数据是已加载真实 FULL 区块或 MCA 已保存 FULL NBT；不根据种子猜测地形，不加载/生成未探索区块。
- 服务端原始地表采样写入世界目录 `cartograph-surface-v3/r.<rx>.<rz>/c.<cx>.<cz>.gz`；压缩的16×16像素、地表高度、特殊方块、海水深度、实际结构，不包含资源余额或测绘授权。
- 读盘时验证 MCA 区块分配项、该区块保存时间戳、GZIP CRC、维度目录、坐标和格式版本；过期/损坏回退真实 NBT 解析。**内存中尚未保存到世界的方块改动不会写入服务端持久缓存**。
- 客户端完整地图页 `<游戏目录>/cartograph/page-cache-v5/<世界标识>/<地图册>/<维度>/p.<x>.<z>.gz` 后台写入；重启进入相同地图册先读磁盘像素，再由服务端验证需要更新的瓦片。不会使用客户端磁盘快照扣除/发放物品。
- 4 张128×128瓦片并行请求；服务端扫描16×16区块快照受主线程总预算约束。客户端最多1400个 CPU 地图页、140个 GPU 纹理；离开后返回旧区域直接复用内存/磁盘，不再重新访问整张世界。
- 监听放置、破坏、流体和邻块通知，延迟3-4 tick合并相同区块变化；向仍持有地图册的玩家发送单页失效，客户端保留旧图直到新图可显示。
- 设置 → 缓存与性能：后台2/4/8线程，主线程2/4/8ms预算；刷新全部已测绘区域支持暂停/恢复/取消，按启动时的测绘区块快照做稳定进度，不重新解锁或扣墨水、纸值。
- 第一人称手持地图册：悬浮小地图自动隐藏，改用独立羊皮纸装订风格的手持视图；换下地图册恢复原来的小地图开关。
- 地图右下角普通加载状态不再显示上下波动的内部待处理队列数；后台全量刷新才显示总量/完成/失败。
- 新版网络协议版本为 14；单人模式自动同时升级逻辑服务器/客户端，多人服务端和客户端须保持一致。

## 验收

1. 连续打开地图并拖动至远处再拖回来：旧画面直接出现，不再完整重扫。
2. 退出 Minecraft 后用同一存档、同一地图册重开：先出现磁盘缓存画面，再局部更新。
3. 挖块/放块/改造水体：当前地图瓦片局部刷新，不扣额外墨水；离线修改存档后手动全量刷新验证新地貌。
4. 在设置中选4后台线程/均衡，开始刷新：总数固定、完成单调上升；暂停、继续、取消正常。
5. 手持地图册时查看小地图是否自动隐藏，羊皮纸手持视图与玩家方向是否正确；切换快捷栏恢复HUD。
6. 旧地图、旧地图纸/墨水/颜料/发光余额、区域、标点、世界不被重置；新旧页面缓存格式损坏时必须退回真实世界。
