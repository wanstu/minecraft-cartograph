# Cartograph · 三风格地图 + 区域命名（交互原型）

设计文件：`preview/cartograph-three-styles-regions-hifi.html`，完全离线的单文件 HTML，适用于浏览器直接打开。

## 三种风格

- **像素（Minecraft）**：保留方块化地表和材质块的视觉特征，参考 VoxelMap 的使用体验，而不是现实卫星地图。
- **写实（现代地形图）**：自然地貌颜色、山体阴影、河流与地表道路。
- **手绘（古式地图）**：羊皮纸、墨线、山峦与树林符号、古式地名文字。

三种风格共享地表、地理坐标、标点和命名区域；切换风格不再次扫描、不消耗墨水。原型地图内容全部是演示数据，不读取真实 Minecraft 存档。

## 区域命名交互

- 顶部新增 **区域** 按钮，打开命名区域列表。预置示例：北境海（海域）、苍岚山脉（山脉）、白河谷地（河谷）、雾松林（森林）。
- 点击「在地图上圈选区域」，连续单击添加多边形顶点；至少三点后双击、单击起点、右键或点击「完成圈选」结束。支持撤销顶点、Esc 取消与鼠标滚轮缩放。
- 在弹窗填写**地名、地理类型与注记颜色**，保存后立即在三种地图风格上按各自风格绘制名称。选中的区域使用边界提示。
- 区域列表支持定位、改名/改类型/改颜色、**重新圈选边界**和确认删除。右键已命名区域可打开编辑和定位操作。
- 「图层」和「设置」可独立显示或隐藏区域名称、区域边界；默认仅显示名称，避免永久轮廓遮盖底图。
- 浮窗与标点保持独立。区域数据保存在 HTML 浏览器的 `localStorage` 中，刷新后保留；无法访问存储时仍能单次使用。

## 游戏内实现边界

区域命名只是**地图注记层**，不代表地图页购买、所有权声明、领地系统，不修改真实区块，也不允许通过区域名称泄露尚未测绘的信息。游戏版建议独立模型 `NamedRegion{id, atlasId, dimension, name, type, color, polygonBlocks, labelAnchor, revision}`，服务端校验坐标与顶点、存储并同步给该地图册允许访问的玩家。可见区域标签优先避免重叠，按缩放级别控制密度。

本轮只做 HTML 高保真原型和交互测试。**没有把区域命名实现到 NeoForge JAR，也没有推送正式版本。**
