# Cartograph — 2026-11-10 悬浮与手持地图预览一致性修复

## 真实缺陷

- 当前 eadm 的 config/cartograph-client-map.properties 中，用户保留的浮动小地图设置为 hudFlags=63, hudSize=360, hudX=1.0, hudY=1.0, hudZoom=0.5, round=true, style=PIXEL。
- 因为用户正手持地图册，游戏走 drawHeld，把画面强制固定到约120物理像素的右下角方形古式，同时忽略上述大部分浮动地图设置。
- 但旧“调整小地图位置与大小”总是绘制 AtlasHud.draw，展示360物理像素的圆形像素地图。因此预览与当前实际手持画面完全不一样，并非分辨率或用户操作问题。

## 修复

1. 设置→小地图明确区分两个独立模式：悬浮小地图（未手持地图册）与手持古式地图（手持地图册）。每种模式有显式预览/调整入口。
2. 调整界面的两种模式直接调用游戏正式 HUD 渲染方法 AtlasHud.draw 与 AtlasHud.drawHeld。尺寸/定位也分别调用正式 AtlasHud.layout 与 AtlasHud.heldLayout。两个按钮切换预览。
3. 手持地图位置、尺寸、缩放、图标/方位/坐标/北向选项单独存入原设置文件的新键，不覆盖既有悬浮图个人配置。
4. 编辑手持时保留真实游戏的第一人称书本模型；编辑悬浮时临时隐藏手持书本模型，以模拟放下地图册后的真实悬浮样式。
5. 取消恢复两个模式的位置和尺寸，完成统一保存；不改存档测绘墨水和纸张账本。
6. 恢复两种地图默认是用户主动操作；绝不自动覆盖旧配置。

## 验收

- 手持地图册并打开 设置→小地图→预览及调整手持地图，游戏中的地图页位置、尺寸、方位、图标和古式样式应和预览一致（手部自然动画除外）。
- 点击悬浮图后应看到保留的360物理像素圆形像素图；手持书本隐藏。把地图册切到非手持后实际悬浮图应保持一致。
- 分别拖动、缩放，完成后重进编辑器/重启游戏都能恢复；取消不保存改动。
- 坐标、方位刻度、锁定北方等开关仅影响所选地图模式。
- Minecraft GUI缩放变化时，两种渲染/预览共用相同物理尺寸换算。

## 质量边界

通过编译、缓存回归及静态HUD一致性校验，真实GUI仍需要 eadm 游戏内验收。
