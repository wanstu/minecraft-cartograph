# Cartograph P0 — 地图持久化与增量更新（2026-11-10）

## 开发环境
仅在 dadm 的独立 worktree adm/cartograph-p0-persistent-survey 开发。NeoForge 1.21.1 客户端通过 Xephyr DISPLAY=:92 运行。New World 是由 dadm 上轮 QA 的测试存档复制得到，无 eadm 操作，未修改原始游戏存档。

## 数据层契约
- 世界地表缓存：WorldSurfaceIndex / SurfaceDiskStore 按真实 FULL MCA 时间戳校验；不依赖玩家持有的地图册，绝不生成区块。
- 已测绘蒙层和已彩色蒙层：AtlasWorldData SavedData 中两个独立 NBT list 持久化，只由服务端授权。
- 地图显示缓存：ClientPageStore 以世界、地图册ID、维度及页坐标隔离缓存，不授予测绘权限。
- 地表变化只更新像素，不能扣墨水、颜料、发光墨水或地图纸。

## 本轮实现
1. 本地磁盘页优先异步加载；最多等待16tick（0.8秒），失败立即请求服务端数据，不会无限等待。
2. 有缓存的地图先显示再延迟10秒服务端确认，识别世界离线变化；部分绘制页和完整页分别采用正确的周期。
3. 方块变化比较真实 SurfaceTile；普通付费区域更新以16×16局部补丁送给客户端，旧GPU纹理保留直到上传，整页重扫不再是默认路径。
4. 失去已生成区块或用户显式批量刷新仍走整页回查，确保正确性。
5. 标点、纸值、指南针等非绘制操作的成功反馈不再触发不必要的强制地图扫描。
6. 读取旧地图册历史存档不依赖实时ModConfig初始化；保留存档中的固定纸张范围。
7. 玩家快速连续方块修改会重新失效旧样本，避免旧快照覆盖后一次变化。
8. 网络协议版本提升至15，服务端与客户端需安装相同版本的新版JAR。

## dadm 真实游戏验收
- Minecraft Creative 原生测试世界成功填充墨囊，至少667个区块完成测绘，写出真实的磁盘地图缓存。
- 游戏内执行/fill，64个方块由钻石块更换为绿宝石块。对客户端两份真实缓存页逐像素比较：编辑区内64像素改变，编辑区外0像素改变，测绘和彩色掩码及余额均不变；更换时没有整页重扫日志。
- 正常保存退出世界，退出整个游戏，重启Java客户端并重新进入复制存档：画面先用本地缓存显示。
- 重新进入后仍有测绘覆盖667/1024，墨水445.3，颜色覆盖0/1024；存档data/cartograph_atlases.dat存在。
- 离线数据验证后原始缓存可能被新的完整服务端快照取代，该快照检测到自然生长的其他地表变化（比编辑前另有5像素、4处高度变化）。注意区分：单次16×16补丁区块外0变化；跨重启完整世界重新验证可接受真实自然变化。
- Native CacheSelfTest涵盖：MCA时间戳失效、16×16 copy-on-write、世界/地图册/维度隔离、双蒙层与余额保持、空白无墨水缓存、服务器SavedData NBT两次序列化、损坏缓存安全回退。
