# Cartograph V4 开发与验收任务

以高速、可靠、稳定、低耗为目标。地理采集独立于地图可视范围；不兼容、不迁移旧版 Cartograph 数据，不修改用户存档或其他项目。
状态：已验证 = 对应核心或既有实机测试通过；原型/部分 = 不能视为发布验收；待实机 = 已实现且需运行验证；未完成 = 尚未交付。
最新实机参考为 8360b57；之后的 GPU 常驻、局部分组及 2D/2.5D 等高线图层只有核心/API 编译验证。

## 执行顺序与发布门槛
1. 解除 DADM 正常源码同步/构建阻碍；验证最新 GPU、拾取及 2D 等高线路径。

3. 修复关键采集可靠性、存储回收及渲染接缝问题；大型真实存档及整合包性能对照。
