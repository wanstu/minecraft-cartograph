# Cartograph 真实测绘链路 · 当前实施与验收记录

日期：2026-11-09；目标：Minecraft 1.21.1 NeoForge 21.1.265 / Java 21。

## 已实现的调用链

1. 原版工作台：空地图 + 皮革 + 羽毛 = 地图册；地图册 + 空地图扩充 128×128 的地图页（保留物品组件）。
2. 墨囊、红黄蓝染料、发光墨囊和指南针目前使用临时交互：**主手地图册，副手耗材，右键**。指南针可潜行右键（空副手）取回。
3. **M** 键（地图册在背包即可），或手持地图册直接右键，打开新的游戏内 **AtlasScreen**；地图页用方向键切换，滚轮缩放。手持时也有简易 HUD 小地图。
4. 客户端发 `cartograph:request_page`（只有页坐标），服务端校验玩家确实持有地图册，校验页位于相对初始中心按螺旋顺序扩充的已购买范围。客户端无法指定世界、提供图像或绕开容量限制。
5. 服务端最多处理 **2 个区块/服务器 tick**，使用 `getChunkNow` 读取内存中已经 FULL 的区块；若未加载，则读取对应维度的 `region/r.*.*.mca` **已保存**的压缩 NBT；校验 Status=`minecraft:full` 和 xPos/zPos。
6. 对真实 FULL 区块，读取实际 `WORLD_SURFACE` 高度图和 `sections.block_states.palette/data`，采样地表方块原有地图颜色。**不使用 Seed/GeoWorld 模型，不调用会加载、生成新区块的 API**。格式不支持、未生成、未购买、资源不足都保持空白。
7. `AtlasWorldData` 放在 Overworld `SavedData`，以地图册 UUID 为键持久化：**服务器权威的资源余额、扩展页数、首页所在维度/位置、已支付区块及彩色账本、真实地表缓存**。物品组件只作同步镜像，不能通过复制过时的物品快照恢复已花资源。
8. `SurveyLedger` 对一个区块首次测绘、首次上色分别扣费；已支付区块重新采样和更新 **不再扣任何墨水或颜料**。已消失的区块不显示过时缓存，但账本保留，恢复后不会二次扣费。
9. 服务端完成一页 64 区块扫描后下发 `cartograph:page`（128×128 像素 + 彩色区块掩码 + 资源余额 + 指南针状态 + 维度），客户端默认严格黑/白两色，染料生效后才显示彩色；指南针未安装不显示玩家指针。
10. 客户端在地图打开或手持状态下周期性重新申请已购买页，反映最新加载或已保存的地表变化；页面轮询不会自动创建新 Chunk。

## 自动测试（本轮在 dadm 已完成）

- `bash scripts/verify-common.sh` 通过：128×128 地图页、1024 个螺旋页的正反校验、负坐标/超大输入、防重复扣费、三种状态与真实 zlib MCA 只读解码。
- `java/adapters/1.21.1-neoforge/gradlew check build` 编译构建通过；JAR 结构验证通过。
- NeoForge `runServer` 开发启动，日志显示 Cartograph 0.1.0 载入，独立启动测试世界出生区生成完成，`DedicatedServer: Done`；限时任务随后停止，不常驻后台。
- 从该新建世界读取 `r.0.0.mca`：609 条有索引条目全部能通过独立 zlib/NBT 读取器解压（第一次检查）；两份区域文件共检查到 841 个 chunk 记录，其中 49 个 FULL，其余只完成部分生成阶段。
- FULL 样本验证：`Status=minecraft:full`，`WORLD_SURFACE` 高度图含 37 个 long；section palette 的 packed long 长度与 1.21.1 格式一致。
- 这些检查验证**服务器启动与真实存档格式**，但**不等于玩家实机 UI 验收**；还需要实际进入游戏查看像素、墨水余额与存档重新载入。

## 已知缺项和边界（尚未完成，不能声称支持）

- 地图界面目前是可玩的**单页地形图**，方向键切换；尚未实现跨页连续拼接与完整大图拖动。
- 尚未迁移 HTML 中的自定义标点编辑、图标/颜色、发光标记扣费、原版地图提取/拓印。
- 暂未绘制地表自然结构自动图标、原版道路/铁路或 Create 曲线轨道；明确不显示地下线路。
- 暂未开发最终的地图册 GUI **通用耗材格 + 指南针格**；当前使用副手投入的临时交互。
- 尚未实现地图册对其它维度的独立购买和页目录；首次绑定的维度以外不会泄漏任何已有地图。
- MCA 外部大区块 `.mcc`、LZ4 或第三方不标准压缩类型仍保留空白（安全降级）。
- 未进行 Minecraft 客户端实机操作、多玩家联机、长时间海量区块、崩溃/存档还原一致性测试。

## 接下来的执行顺序

1. NeoForge 客户端验收：地图册物品/配方、无墨水黑屏、墨囊首绘、染料变彩色、指南针显示玩家、旧区块修改后免费更新、负坐标和已生成但未探索地区。
2. 大地图 GUI 从按页切换升级为平滑拖动、跨页图块拼接，并实现通用耗材槽、非耗材槽。
3. 实际地表结构查验/自动图标，以及原版道路铁轨、Create 轨道图层，采用本地已确认的真实表面信息。
4. 自定义标点的增删改、颜色和图标、发光墨水计费，取出原版地图的安全拓印。
5. 游戏内压力、并发、复制/掉落、重启恢复验收；然后推广到 Fabric 及其它版本。正式发布开关保持关闭。
