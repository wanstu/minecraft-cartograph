# Cartograph · 真正的已生成区块测绘与验收

2026-11-09 · Minecraft 1.21.1 NeoForge / Java 21。以下“已实现”指源码接入、编译通过；**并不代表已经完成客户端点击验收**。

## 数据安全与测绘机制

1. Minecraft 原版空地图+皮革+羽毛合成地图册；地图册+原版空地图在普通工作台扩展测绘页。
2. 每页 128×128 方块，8×8个区块，负坐标按数学向下取整。购买的页以最初打开位置为中心螺旋排列；尚未购买/生成页留白。
3. 通过 Minecraft 服务端 `getChunkNow` 仅读已加载FULL区块；不加载区域则 `McaChunkReader` 只读 `region/r.x.z.mca` 已保存、状态确认为 `minecraft:full` 的 NBT；不使用Seed或GeoWorld模型，也不调用强制生成或加载chunk的接口。验证 chunk 坐标和高度图、真实方块palette。MCA外部 mcc / LZ4 暂不支持时保守留白。
4. 地表图按该区块的最高实际地表方块采样。老区块的真实变化会在下一次轮询采样中刷新，不再额外扣墨/颜料。区块首次测绘、首次上色分别在 `SurveyLedger` 记账，已支付后免费重绘。
5. `AtlasWorldData` 用服务端SavedData持久化（每个atlas UUID/所在维度/位置/页数、耗材余额、地图数据、标点/计费状态）。客户端没有服务端扣费、写像素权限。网络按atlas UUID与当前玩家身上所持物品绑定。
6. 服务器每tick最多两次16×16采样，客户端地图视野最多24页缓存，服务端对页请求限速；图层更新只含当前已付费的真实FULL区块，不因读取而生成/探索新区块。
7. 普通地图册绘制黑/白两种颜色，红黄蓝一组染料才解锁彩色。墨囊首次才能测绘。安装指南针显示玩家自身位置；取出不消费。
8. `MapNetwork` 消息只有页索引、标点及耗材请求，不能让客户端读未购买维度/区块；资源补充来自真实玩家背包，不接收任意数量。
9. 右键地图创建标点，右键已有标点编辑/删除。发光墨水首次标记消耗1×倍率、之后改图标/颜色/名字不重扣。不同的形状、颜色和名字保存在服务端。
10. 右键“取出地图”：服务器核对范围与已付费区块，消耗一张原版空地图并创建原版0级已填充地图；图册原页不删除。
11. 地表道路/铁轨仅识别真实 `minecraft:dirt_path`、四种原版rail块和`create:track`方块（Create可选，不是依赖）；目前只实现实际地表方块级别轨迹，尚未处理Create曲线网络连线。
12. 结构图标要求FULL区块内实际结构 start、实际地表具有结构特征方块双重确认。已涵盖部分原版地表结构（村庄、沙漠神殿、丛林神庙、雪屋、沼泽小屋、前哨站、林地府邸等），不画地下结构；尚未覆盖所有合法地表自然结构。
13. 通用耗材 UI 输入入口点击后选择背包内可消耗材料，指南针独立可装/取。客户端可在图册弹层调节三个倍率的滑块0–10、步长0.1；**仅服务端OP/单人世界主有修改权**。

## 已通过的自动验证

- 公共Java17核心：测试128²页面、1024螺旋扩展、负坐标、超大请求、首次账本消费与永久免重扣、Minecraft MCA真实zlib解码。
- NeoForge Java21源码构建：`./gradlew check build` 完成；JAR内 loader mod id、common类、游戏业务类、assets文本与两套配方都有校验。
- 实际NeoForge开发服务器`runServer`载入Cartograph并打印`DedicatedServer: Done`，没有发现mod loading失败；限时运行结束。
- 已建立NeoForge测试世界，扫描其`r.0.0.mca`发现609条chunk索引均成功独立读取，扫描两份region共841条记录，其中49条FULL；实际FULL区块有真实高度图与section palettes。
- 这些测试**不能代替玩家客户端UI、完整真实地图像素、单/多人存档、Create曲线与服务器负载实测**。

## 仍需人工验收（不可提前声称正式发布）

1. 在安装NeoForge的Minecraft1.21.1客户端实际打开大地图（M、右键），测试小地图和连续平移、缩放、跨页无误。
2. 初始无墨水不能测绘，首次填入墨囊后能读取“已生成但玩家没去过的FULL区块”，从不读取未知区域；0倍率仍需解锁条件。
3. 三原色全齐才能彩色化，墨水/颜料余额和重启后的扣费相同；修改房屋、河道、修路后地图更新免费。
4. 在地图册中创建/编辑/删除标点，图标颜色和名称正常，发光首消耗1、编辑免耗，断线重连仍存在。
5. 从地图册取出原版地图，真实消耗一个空地图，原页不减少；地图颜色、页面位置与原版正常。
6. 地表结构真实存在才标记，拆除后变化；无地下道路、铁路、未生成结构、地下要塞/矿井图标。
7. Create 铁轨实块定位，弯曲轨道后续升级；不存在Create模组时也不能崩溃。
8. 多人、库存复制、防充值与余额重算、地图丢弃及领取、跨维度、负坐标、存档还原、崩溃一致性和大地图性能。
