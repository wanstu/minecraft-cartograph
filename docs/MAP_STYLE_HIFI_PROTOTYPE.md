# Cartograph 写实 / 手绘双风格高保真设计原型

文件：`preview/cartograph-map-styles-hifi.html`（完全离线单文件，可直接用浏览器打开）。

## 设计意图

写实：参考常见现代地形地图的自然地表颜色、山体阴影、森林、湖泊、河流及道路/铁路线。不是 Google 卫星影像，重点是清楚地辨认地形。

手绘：同一份地形输入，在羊皮纸色地形上表现墨线等高线、手绘海岸、树林符号、少量山峰符号、水纹和古式地名。不是对写实图全局套黄色滤镜。

这两个画法必须共享**一份地表事实**，不准通过世界 Seed 预测未生成或地下的信息。升级成彩色需要投入三原色；写实/手绘仅改变渲染，不改变耗材逻辑，也不额外扣墨。

## 原型演示功能

1. 默认显示同一地形的左右对照，中线拖动可以比较同一河流、路网、村庄的定位。
2. 顶部可快速切换写实、手绘、对照；在「设置」弹窗中也可选择写实或手绘，并看到缩略预览。
3. 地图全屏支持鼠标拖动、滚轮缩放；画面不因用户操作而重新计算世界地表。
4. 图层可开关道路、铁路、结构、玩家标点与等高线。
5. 右键地图可增加原型标点并选择名字、图标和颜色。
6. 地图册资源信息使用悬浮窗，没有左上角无功能装饰标识和全屏固定底栏。

## 技术与验收边界

这是专门用于**视觉验收**的 HTML 原型：内置确定性演示地貌，不会读取 Minecraft 存档，也不表示世界数据索引、两种风格游戏内渲染、增量 GPU 纹理已经落地。渲染先按演示地形生成两张画布；切换风格、拖动、缩放仅重绘现有画布，不执行地形采样。

截图对照设计稿时，使用 1686×895 视口。用户确认风格后，才在真实 `SurfaceSnapshot` 上实现这两套渲染策略。
