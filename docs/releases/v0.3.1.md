## Cartograph V3.1 · 0.3.1

适用于 **Minecraft 1.21.1 · NeoForge 21.1.265+ · Java 21**。在客户端和服务器的 `mods/` 目录安装同一版本。

- 进入世界后自动收集真实地表。按 **M** 打开原生地图，也可从设置打开 WebUI。
- 大范围地图缩小时显示已探索地形的概览，放大时切回地表细节。
- 支持图层、结构标记、自定义标点，以及分别调整地图字号和 UI 缩放倍率。
- 区域索引加快已有磁盘缓存查找。内容相同的已缓存区块回传时只做校验，地形变化时更新纹理和磁盘。
- 改进退出存档、切换维度和后台补图的恢复流程。

下载 `Cartograph-V3.1-0.3.1-mc1.21.1-neoforge.jar`，可使用附件中的 `SHA256SUMS.txt` 校验。
