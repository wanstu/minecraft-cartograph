## Cartograph V3.1 · 0.3.2

地图册现已支持 Minecraft 1.21.1 和 26.3，每个版本提供 Fabric 与 NeoForge 安装包。进入世界后，地图会在后台记录实际生成并保存的区块。按 **M** 打开原生地图，也可从设置打开浏览器地图。

| Minecraft | Java | Fabric | NeoForge |
|---|---|---|---|
| 1.21.1 | 21 | Fabric Loader 0.19.4+ 与适用于 1.21.1 的 Fabric API | 21.1.265+ |
| 26.3 | 25 | Fabric Loader 0.19.5+ 与适用于 26.3 的 Fabric API | 26.3.0.40-beta 或更新的 26.3 版本 |

- 两个游戏版本共用原生地图界面，包含拖拽、缩放、图层和自定义标点。字号和界面缩放可分别调整。
- 地表缓存按游戏版本、存档和维度保存。已保存区块发生地表变化后，后台会更新对应地图内容。

选择文件名中带有对应游戏版本和加载器的 JAR，放入游戏的 `mods/` 目录。联机时，客户端和服务器使用同一 Cartograph 版本。可用附件中的 `SHA256SUMS.txt` 校验下载。
