# Minecraft Cartograph — 7项截图验收反馈（2026-11-10）

## 修复范围
1. 大地图图标与玩家标识随缩放收缩；缩远时隐藏文字标签，避免图标盖住地形。
2. 不再发送扫描到8、32区块时的半张地表图；服务端后台照常逐区块处理，直到64/64完成才更新一整张瓦片。老纹理持续显示，防止半成品覆盖成移动空白条带。
3. 主手地图册使用下方正中、打开的双页古式地图册外观；不再使用屏幕右下固定小方框。
4. 副手地图册使用较小的左下方位置。主/副手均按屏幕宽高定位，取消修改手持地图位置的入口。
5. 悬浮小地图坐标改为圆形实际内接弦宽约束、单行自动缩放，不再有伸出地图区域的双行黑色信息条。
6. 手持地图册的地形风格、地图缩放、方位开关、标点图层直接复用小地图同一套设置；形状保持展开的古式书本（并非圆形小地图）。新书本绘制内容来自Cartograph自己的真实地表采样，不读取Antique Atlas的数据或素材。
7. 地图册扔掉一会再拾取：清除无效网络请求但保留已确认页面、纹理、测绘覆盖与内存缓存。切换不同地图册或维度仍严格隔离；无资源扣费变化。

## 实现说明
- eadm 已安装 Antique Atlas-1.21.1-8.0.1-NeoForge.jar；观察它使用 HeldItemRendererMixin 区分主手和副手的渲染方式，借鉴固定物理手持布局，但**本项目没有复制 GPLv3 源码、贴图**。
- 新书本皮革、羊皮纸边框由自己的UI绘制产生。手持物品的普通库存图标在一人称时被抑制，以免叠出两个不同的书本。
- UI预览仅针对可拖动的悬浮小地图；主手/副手不允许拖动，因此不再提供虚假的手持编辑预览。
- 不改变真实地图数据、存档记录、墨水/地图纸/染料与发光墨水机制。

## 验收
1. 大地图拉远至0.5x、1x、3.2x，确认图标跟随缩小；更近时大小合理。
2. 手动刷新和移动视野时，已有完整地图不出现临时条纹；新地图页准备好后整体出现。
3. 主手握地图册：打开式双页书本居中；放副手：单本靠左；都不在右下重复显示地图框。
4. 选择“像素/写实/手绘”三种风格，分别检查手持地图内容切换；显示东西南北/坐标按钮作用于两种显示。
5. 退到极小悬浮地图、圆形/方形，坐标均不超过地图轮廓。
6. 扔掉并拾取同一本已绘制地图册，确认地图不清空，也不触发全区域重新扫描。

## 测试边界
已设置静态回归 + Gradle构建和缓存读写自测。依旧需要运行中的 eadm 游戏视觉验收，特别是打开式书本的大小和手部遮挡。
