## 修复内容

1. SurfaceChangeMonitor：邻块更新不是地图变化。将旧地表快照与世界变动后的实际16×16地表快照比较；只有确实变化才通知地图页失效。植物/树叶等同样本更新不再触发整页64区块重扫。
2. 邻块通知做20tick合并，最低120tick复查间隔；玩家直接放置/破坏可在3tick复查；同一来源最多1024挂起，主线程每tick处理最多4个、耗时预算约2ms。
3. CartographClient：完成而没墨水、没绘制的空白页延长重查间隔至全页级别；补充材料后仍通过强制刷新立即显示，地表实际改变也能触发局部刷新。
4. ClientPageStore：完成且在范围内的空白/无墨水页也写入持久磁盘快照，避免重启把“无材料”误当成“从未扫描”。
5. AtlasScreen：地图工具栏、普通状态栏在中等分辨率以更大的整数物理像素倍率绘制；设置弹窗因高度限制沿用较小整数倍率，避免非整数缩放造成文字模糊。
