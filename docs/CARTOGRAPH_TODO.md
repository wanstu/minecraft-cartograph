| 视口 | 候选区域 | p95 原 → 新 | 每次分配原 → 新 |

| 近景 | 1 | 0.231 → 0.002 ms | 39,776 → 463 字节 |
| 远景 | 8 | 0.838 → 0.004 ms | 309,744 → 2,352 字节 |
