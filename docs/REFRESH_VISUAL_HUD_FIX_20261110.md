# Cartograph 2026-11-10 刷新闪烁与HUD精简

## 缺陷根因
- 已完成的64区块瓦片在收到8/32区块中间数据包时被当作新数据覆盖，丢失剩余像素并在后续完整包恢复，形成截图中的跳动空块。
- 手动刷新每完成一个16x16区块都通知重新读取同一128x128瓦片，放大扫描与网络负担。
- 手持地图册物品模型放大1.45倍，另叠加168 GUI像素大的地图框及坐标条，导致遮挡视野。
- 小地图编辑界面中悬浮预览和手持模型同时绘制；大标题/底部按钮和额外坐标条浪费屏幕。

## 修复
- 完整瓦片始终保留旧贴图，忽略8/32区块中间包；只有64区块最终包才切换；首次显示未缓存瓦片继续分步真实绘图。
- 每个瓦片所有已测绘区块后台刷新完毕后才通知一次客户端刷新；消除无in-flight时的冗余二次扫描。
- 手持物品模型缩放0.72；独立古式地图按约120物理像素预算绘制方形羊皮纸简框，不显示坐标条和四方向大字，保留指南针状态控制的玩家方向。
- 小地图初始默认130物理像素，默认仅显示地图/图标，其余可选；保留旧用户个人设置，手动恢复紧凑默认。坐标显示只在小地图内部；尺寸/位置编辑直接使用正常悬浮小地图绘制并隐藏手持书本模型。
- 小地图设置明确针对悬浮小地图（手持地图册时自动收起）；手持形式独立保持古式地图样式。

## 测试
- 保留原有存档、测绘墨水/地图纸/染料/发光墨水账本，不触发新扣费。
- 新区域无旧瓦片时允许真实8/32/64里程碑显示；旧瓦片刷新不允许空白闪现。
- eadm 视觉/运行性能需要实际游戏内验收；编译或静态脚本不代表已验收。
