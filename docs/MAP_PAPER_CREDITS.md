# 地图纸值：投入与消耗（2026-11-10）

- 地图纸值是地图册 ID 对应的服务端权威余额，与测绘墨水 / 颜料 / 发光墨水分别计账。
- 在「地图册 → 材料槽」投入一张原版空地图，增加纸值：基础 4.0 × 投入倍率（默认每张空地图可扩充 4 页或取图 4 次）。
- 「地图设置 → 耗材与倍率」第四项「地图纸值」：投入倍率、消耗倍率均限制 0.1～10.0；默认 1.0/1.0。
- 「永久地图纸」默认关闭；开启后须至少投入过一次原版空地图才能生效，后续扩页和拓印不扣余额。
- 大地图扩页、拓印原版地图统一按一次 1.0 × 消耗倍率付费，不再要求拓印时背包内必须有空地图。
- 拓印只有真实地表生成的可绘制像素才成功；无像素、断线、地图册移走、纸值不足都不扣纸值。扣费在拓印确认完成时单次发生。
- 余额与永久解锁门槛存入 AtlasState 数据组件和 cartograph_atlases SavedData。旧存档无字段时默认 0 / 未投入，不重置已有地图页、测绘墨水和蒙层。
- 创造模式按旧行为免材料消耗；配方台历史「地图册+原版空地图」直接增加一页仍保留，避免变更已有生存配方；大地图内扩页、拓印统一使用纸值。
- 新版修改了网络协议版本，客户端与服务器必须安装同一版 JAR。

验收：默认投入 1 张空地图余额为 1.0；取图 1 次余额变 0；再投入 1 张扩页后余额为 0；投入 2 张 / 修改独立倍率 / 永久开关 / 存档重启 / 与墨水余额独立核验。

## 2026-11-10 扩面、性能和界面修复

- **默认每页 512×512 方块**：每页测绘面积是原来的 16 倍；地表继续分 128×128 的原生采样瓦片保存，禁止直接放大低分辨率贴图。
- 大地图「设置 → 大地图 / 风格 → 单次扩页覆盖范围」允许 128 / 256 / 512 / 1024 / 2048 方块；选项存于服务器配置，设置对新地图册生效。地图册初次建立后将尺寸写入世界 SavedData，避免改配置导致已有覆盖索引漂移。
- 旧存档缺失尺寸字段默认升级为 512×512，不扣纸值、不破坏已有测绘 / 彩色账本。初始纸张范围以地图册原锚点**居中**，不会把玩家挤到已覆盖地图角落。
- 地表索引不因放大范围主动生成新区块；未生成区块仍空白、缓存按实际屏幕需要扫描。
- 服务端最多 6 个区块 / tick，附带约 2.5ms 主线程时间预算；按需后台读取已存档的完整区块。
- 已完成瓦片重用内存纹理，降低无修改时的服务端重新校验频次（普通地图页最短 3600 tick，约 3 分钟）；扫描只返回完整快照，不再分别上传 8/32/64 进度纹理。
- 材料变更才刷新必要的测绘授权；地图纸、指南针和标点的修改不再强制重绘全屏。
- 打开弹窗不再绘制底图上的玩家文字、区域文字、标点文字，弹窗独立高 Z 层。文本按最终屏幕**整数像素倍率**渲染，避免浮点缩放造成糊字。
- 缓存目前是游戏客户端与服务端**内存缓存**，退出游戏后会重建；跨游戏启动的持久地表缓存仍需单独设计，不能把「本轮消除了不断重新扫描」误说成「完全无重采样」。


## 2026-11-10 地图瓦片、按钮、提示修复
1. 删除非正式原型的右下角独立定位按钮；地图界面按 Home 仍能定位玩家或地图册锚点。
2. 移除地图工具栏文字、样式预览标题及选中按钮文字的阴影，避免黑字产生叠加式假粗体。
3. 设置或材料槽弹窗打开时，服务器反馈会在弹窗上方展示约 7 秒，不会再被隐藏。
4. 大地图每 10 tick 自动补齐当前视野缺失的瓦片，不再受 30 秒补充队列间隔影响；平移/缩放优先重排当前可见页。
5. 完整瓦片使用内存缓存，常规重检 10 分钟；未完整描画的瓦片约 30 秒后可重检，数据不被清除。
6. GPU 纹理页缓存上限192，后台磁盘读取3线程；服务端预取只对未加载磁盘区块排队，不提前采样已加载世界区块。
7. 大地图背景与未绘制瓦片统一纸张底色，消除像云层的浅灰方形空洞；游戏云不是世界方块，不参与地图采样。
8. 未生成区域保持空白，不生成新世界、不扫描地下；仍需游戏内视觉和性能验收。
