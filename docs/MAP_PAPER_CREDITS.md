# 地图纸值：投入与消耗（2026-11-10）

- 地图纸值是地图册 ID 对应的服务端权威余额，与测绘墨水 / 颜料 / 发光墨水分别计账。
- 在「地图册 → 材料槽」投入一张原版空地图，增加纸值：基础 1.0 × 投入倍率。
- 「地图设置 → 耗材与倍率」第四项「地图纸值」：投入倍率、消耗倍率均限制 0.1～10.0；默认 1.0/1.0。
- 「永久地图纸」默认关闭；开启后须至少投入过一次原版空地图才能生效，后续扩页和拓印不扣余额。
- 大地图扩页、拓印原版地图统一按一次 1.0 × 消耗倍率付费，不再要求拓印时背包内必须有空地图。
- 拓印只有真实地表生成的可绘制像素才成功；无像素、断线、地图册移走、纸值不足都不扣纸值。扣费在拓印确认完成时单次发生。
- 余额与永久解锁门槛存入 AtlasState 数据组件和 cartograph_atlases SavedData。旧存档无字段时默认 0 / 未投入，不重置已有地图页、测绘墨水和蒙层。
- 创造模式按旧行为免材料消耗；配方台历史「地图册+原版空地图」直接增加一页仍保留，避免变更已有生存配方；大地图内扩页、拓印统一使用纸值。
- 新版修改了网络协议版本，客户端与服务器必须安装同一版 JAR。

验收：默认投入 1 张空地图余额为 1.0；取图 1 次余额变 0；再投入 1 张扩页后余额为 0；投入 2 张 / 修改独立倍率 / 永久开关 / 存档重启 / 与墨水余额独立核验。
